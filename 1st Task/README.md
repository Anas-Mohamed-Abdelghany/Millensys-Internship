# Millensys Intern — Personal Portfolio

A responsive personal portfolio website showcasing the intern profile, technical skills, projects, and achievements at Millensys Healthcare IT Solutions.

## Overview

This is a single-page portfolio website built with **HTML5** and **CSS3**, designed to present a professional intern profile in a clean, modern layout.

## Features

- Responsive design with mobile-friendly layout
- Card-based UI with smooth hover animations
- Skill tags with interactive hover effects
- Education and projects sections
- Clean typography using Inter font (Google Fonts)
- Gradient background with elevated card components

## Tech Stack

| Technology | Purpose |
|------------|---------|
| HTML5 | Page structure and content |
| CSS3 | Styling, layout, and animations |
| Google Fonts | Inter font family |

## File Structure

## Sections

1. **Header** — Logo and professional title
2. **About Me** — Technical summary and skill tags (PyTorch, TensorFlow, React, etc.)
3. **Education** — Academic background and GPA
4. **Projects** — Portfolio of AI/ML and full-stack projects with GitHub links
5. **Programs & Competitions** — Hackathons, certifications, and awards
6. **Footer** — Copyright and attribution

## How to Run

1. Open `index.html` in any modern web browser.
2. No server or build tools required — fully static.
